# ISIIS Data Processing

Documentation site for the [ISIIS_data_processing](https://github.com/flecaros-mbari/ISIIS_data_processing) repository, which processes imagery and video from the ISIIS (In Situ Ichthyoplankton Imaging System) instrument.

## Contents

- **[Labeling Guide](labeling-guide.html)** — the class taxonomy used to label ROIs (regions of interest) in ISIIS imagery, with example crops for every class.

For pipeline usage, script reference, and installation instructions, see the [repository README](https://github.com/flecaros-mbari/ISIIS_data_processing#readme).
